## About me

你好，我是 **于文涛**。我关注大模型能力如何接入真实工作流，也关心系统背后的检索质量、执行边界与工程实现。

- **在做的方向**：文献问答与 RAG、Agent 工具调用、语音交互，以及开发工作流自动化。
- **开发方式**：人类工程师 + AI 助手。我负责方向判断、审查与拍板，AI 协助检索、实验和代码实现。
- **记录习惯**：把项目中的设计决策、踩坑与验证写成笔记，让经验可以复用。
